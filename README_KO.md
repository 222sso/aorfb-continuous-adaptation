# v66 GitHub 업로드용 코드 묶음

기존 Python 소스68개,선별한 설정/출처 파일,환경 명세와 현재 비교의 경량 수치 CSV7개를 포함합니다.
소스와 수치 파일의 바이트는 기존 라이선스 적용본과 같습니다. 다른 실험 결과를 추가하지 않았습니다.

코드는 MIT,저자 문서·독립 수치 자료는 CC BY4.0이며 LICENSE_SCOPE.csv에 범위를 표시했습니다.
전체 ChEMBL/RedDB 입력,모델,864000개 점수와 Gaussian 기록은 별도 Zenodo용4개 ZIP에 있습니다.
그 자료의 CC BY-SA3.0/CC0 조건을 코드 MIT로 바꾸지 않습니다.

Zenodo URL/DOI는 실제 등록 뒤 입력합니다. 현재 공개 등록이 이뤄졌다는 뜻은 아닙니다.
영문 README의 명령으로 기존 요약값에서 그림1–5를 재현할 수 있습니다.
전체 ZIP은 DATA_ARCHIVES.json의 해시와 tools/verify_downloads.py로 확인한 뒤 별도 폴더에 풉니다.
